# Вечер игр

Игры для компании в одной комнате: каждый со своего телефона, без регистрации и ведущего.

- **Мафия: Классика** — https://balbaevtemirlan.github.io/mafia/#classic
- **Мафия: Выживание** — https://balbaevtemirlan.github.io/mafia/#mafia
- **Выживание** (без мафии) — https://balbaevtemirlan.github.io/mafia/#survive
- **Детектив** — кооперативное расследование в духе true crime, два дела на выбор (с голосованием в лобби): №47 «Тихий дом» и №112 «Невеста в тумане» (пропавшая невеста на свадьбе двух влиятельных семей). Документы на телефонах, запросы улик, кодовые замки, ночные события — https://balbaevtemirlan.github.io/mafia/#detective
- **Бункер** — https://balbaevtemirlan.github.io/mafia/#bunker
- **Побег из комнаты** — квест на время, комнаты с уровнями сложности и таблицей рекордов: «Мастерская часовщика» (Normal, 40 минут) и «Алькатрас» (Unreal, 45 минут: без подсказок, обходы охраны, три ошибки — пойманы). Улики разложены по телефонам — https://balbaevtemirlan.github.io/mafia/#escape
- **Самозванец** — игра в реальном времени на станции «Полярис»: карта из 9 отсеков, мини-задания, устранения, саботажи, люки, собрания — https://balbaevtemirlan.github.io/mafia/#impostor
- **Покер** — техасский холдем на игровые фишки: свои карты на своём телефоне, блайнды, побочные банки и комбинации считаются сами, таймер хода, докупка — https://balbaevtemirlan.github.io/mafia/#poker
- Скоро: **Колония: Стратегия**

## Подробности

Мафия с выживанием: каждый играет со своего телефона, сидя в одной комнате. Ни регистрации, ни ведущего.

Два режима: «Мафия + выживание» (от 4 игроков) и «Чистое выживание» без мафии (от 3 игроков): здоровье, специализации, ночные действия, угрозы и тайные личные задачи.

**Играть:** https://balbaevtemirlan.github.io/mafia/

- 8 сценариев по 12 кризисов: Мёртвый ТЦ, Чёрный ЖК, Последний поезд, Станция «Орбита-9», Чумной город, Отель «Лавина», Кровавая зима, Тварь во льдах
- Две цели: вычислить мафию и не дать упасть общим шкалам до эвакуации
- Особые роли по желанию: Телохранитель, Журналист, Свидетель, Охотник (от 5 игроков), Маньяк, Предатель (от 6)
- Тайные личные цели, предметы в кармане (Оберег, Жучок, Апелляция), ночные события для всех
- Атмосферный звук под каждый сценарий, награды и карточка итогов, рейтинг компании
- Кризисы, общий инвентарь, тайные вылазки отрядов, протокол реплик и досье
- Телефоны соединяются напрямую (WebRTC через PeerJS); игра хранится на телефоне создателя комнаты
